# Developer Portfolio

A responsive personal portfolio website showcasing my projects, technical skills, and technical articles.

## 🚀 Live Demo
- **Website:** [View Portfolio](https://dikshu2004.github.io/Portfolio/)
- **Blog:** [Medium Articles](https://medium.com/@dikshasomwanshi24)

## ✨ Features
- **Responsive Design:** Works smoothly on mobile, tablet, and desktop.
- **Projects Showcase:** Interactive project cards with live demo and GitHub links.
- **Article Reader:** Built-in modal reader for technical blog posts.
- **Resume Download:** Direct access to view/download my resume.
- **Contact Form:** Easy way to get in touch.

## 🛠️ Built With
- **HTML5** – Structure & semantics
- **CSS3** – Styling, responsive grid & animations
- **JavaScript** – Interactivity & modals
- **Font Awesome & Google Fonts** – Icons & typography

## 💻 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/dikshu2004/Portfolio.git
   ```
2. Open `index.html` in your browser (or use VS Code Live Server).
